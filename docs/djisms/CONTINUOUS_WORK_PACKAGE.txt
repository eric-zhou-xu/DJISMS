DJISMS V1 — Codex 连续产品化工作包

目标：从现在开始进入产品化连续开发模式。不要继续制作零散 PoC；目标是交付当前 Mac 可日常使用、随后可分发给其他 Apple Silicon Mac 用户的 DJISMS.app V1。

一、工作方式
在不触及 STOP 条件的前提下，不要每完成一个低风险步骤就停止等待用户批准。
连续执行：
Prior Art/审计 → 实现 → 单元测试 → fuzz/race → 本机集成测试 → reconciliation → 修复 → 下一阶段。
普通代码 bug、编译错误、测试失败、UI/SQLite/构建问题自行解决，不属于人工 Gate。
保留机器可读 evidence/journal；不要反复提交小阶段报告。完整 Milestone 后汇总，除 STOP 条件外持续推进。

二、Milestone 1：完成 Modem 清理
使用已经实机 PASS 的 Archive-and-Purge contract，安全处理当前剩余 eligible ME records。
固定契约：
Preserve → Verify → 临删除前重新读取 slot → storage+index+raw PDU hash 完全匹配 → 具体 AT+CMGD=<index> → confirmation → inventory reconciliation。
永久禁止 bulk delete（包括 AT+CMGD=1,4）。
不允许只凭 index 删除。index reuse、hash/storage mismatch、unknown result、timeout、inventory 异常立即停止 purge；删除结果未知不得重发 CMGD。
每次删除必须 journal；Mac 永久 raw archive 不得删除或覆盖。
完成后验证永久档案完整、Modem 容量释放、USB/ECM 正常、Mac 4G Internet 正常、SIP enabled。

三、Milestone 2：完成 djisms-core
把已通过真实硬件验证的工程代码收敛为稳定 djisms-core，不重新研究已验证的 USB/AT/SMS 基础能力。
Core 至少负责：
- DJI 2CA3:4006 安全识别
- 插入/拔出生命周期
- Interface 2 AT transport
- SMS receive
- GSM7/UCS2/PDU
- multipart SMS
- Class0
- binary SMS 原始保存
- raw archive
- SQLite
- immutable journal
- Archive-and-Purge
- crash recovery
- index reuse protection
- modem capacity management
- typed API
- reconciliation
原则：Preserve Before Transform；raw PDU 是不可替代事实；SQLite/正文是派生查询层；UI 不得绕过 core；不提供 raw arbitrary AT API；不硬编码开发机环境。

四、Milestone 3：完成 DJISMS.app
做标准 macOS App，不是 Terminal wrapper。
V1 用户体验：
插入 DJI 4G → App 自动发现 → 后台接收 → 原始 PDU 永久本地保存 → SQLite 建档/解码 → macOS 原生通知 → Archive Verify/Reconcile → 安全逐条清理 Modem 副本。
实现：
- Menu Bar 状态
- Connected/Disconnected
- SIM/LTE 基本状态
- Modem SMS capacity
- Notification Center
- 通知显示发件人+正文预览
- 本地历史短信列表
- 本地搜索
- multipart 正确显示
- binary/未知内容保留事实，不伪造正文
- 拔插自动恢复
- App 重启自动恢复
- 普通用户可理解的错误状态
- 历史导入不重复通知
通知失败/消失不影响永久档案。
V1 不做复杂 GUI。
永久数据目录：~/Library/Application Support/DJISMS/
本地永久保存；不使用 NAS；V1 不使用云备份；不使用 AI；所有短信统一保存；模块只是临时 inbox/cache。

五、Milestone 4：真实 Mac E2E
自行完成所有不需要用户/第三方外部动作的 E2E。
目标链：SMS arrives → raw durable → SQLite → notification → archive verified → modem copy purged。
测试 App 启动、退出/重启、DJI 拔插、接收恢复、4G 网络、crash recovery、接近满容量、duplicate、multipart、malformed/binary、index reuse、purge 中断、notification failure。
若 Notification 权限必须用户点击，把程序推进到系统提示后再通知用户，不要提前停止开发。
若最终 E2E 必须由另一号码发真实短信，把 App 推进到 READY 后再通知用户发送。不要自行制造第三方短信业务行为。

六、Milestone 5：可分发版本
目标是其他 Apple Silicon Mac 用户独立安装使用。
清除产品代码中的开发机硬编码，包括 /Users/ericxu、UID 501、USB location 0x100000、en6、DHCP 地址、当前 SIM/运营商/registry ID。
使用当前登录用户标准 Application Support 路径。
普通用户不得需要 Terminal、Codex、Homebrew、Go、root/sudo、关闭 SIP、自定义 modem driver、修改 DJI firmware/VID/PID/usbnet/usbcfg。
架构分离 djisms-core + DJISMS.app。App 负责 Menu Bar、Notification、历史短信、搜索、状态、设置、onboarding；Core 掌握 USB/AT/SMS/archive/purge 安全契约。

七、发行工程
产出 DJISMS.app、clean install/uninstall、first-run onboarding、compatibility check、release build、version/build metadata、release notes、最小用户说明。
正式发行目标：Apple Developer ID signing + Apple notarization。
若无 Developer 凭据：不伪造、不降低 Gatekeeper/SIP；完成 development Release Candidate，并明确正式发行尚缺步骤；不得要求朋友关闭 Gatekeeper/SIP作为正式安装方案。

八、Prior Art First
UI、Notification、Menu Bar、Launch at Login、SQLite、App packaging 等 commodity infrastructure 优先 Apple 官方 framework 或成熟可审计实现。第三方 dependency 进入产品前做供应链审查；能用 Apple framework/标准能力/已审核代码完成的，不新增依赖。

九、STOP 条件
仅以下情况停止并请求用户：
1. Archive/Purge contract 异常或 reconciliation 不一致；
2. 原始短信可能丢失；
3. 需要 bulk delete；
4. 需要修改 firmware/NV/flash/VID/PID/usbnet/usbcfg；
5. 需要 root/sudo 或降低 SIP；
6. 需要安装未经审计的系统 driver；
7. 需要实际发送 SMS；
8. 需要实际拨打/接听对外电话并产生业务行为；
9. 需要修改 eSIM Profile；
10. 会产生第三方费用/外部业务行为；
11. 需要 Apple Developer 用户凭据；
12. macOS 明确要求用户本人确认权限；
13. 发现需要重新冻结的重大安全架构问题；
14. destructive action 无法确认影响范围或恢复方案。
普通代码/编译/测试/UI/通知/SQLite/构建问题不是 STOP，自行解决。

十、报告与节奏
Codex PASS 不代表跳过 Gate；Gate、测试、evidence、reconciliation 仍必须存在。只是低风险 Gate 不再逐次人工批准。
不要重复旧报告。除 STOP 条件外持续推进 Release Candidate。
最终主要报告：DJISMS_V1_RELEASE_CANDIDATE_REPORT.md，包含完成/未完成项、实机/自动测试、安全边界、数据生命周期、已知问题、compatibility、文件/commit/hash、安装/卸载、普通用户使用方式、正式发行尚缺事项。

十一、V1 完成标准
至少达到：
Build PASS + Tests PASS + Real Mac E2E PASS + SMS Receive PASS + Notification PASS + Restart PASS + Physical Replug PASS + Archive PASS + Per-index Purge PASS + Crash Recovery PASS + Existing DJI 4G Data Unaffected。
达到后才标记 Release Candidate。
