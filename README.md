# DJISMS 1.2.0 统一版

沿用原版 macOS 界面，统一短信列表、搜索、详情与本地后台接收。

## 安装

下载 Release 中的 DMG，打开后双击 **安装 DJISMS.command**。安装脚本将应用放入 Applications，注册本用户后台接收服务和登录启动入口。需要 `/usr/local/bin/python3`，不自动下载依赖，不需要 sudo。若应用已运行，请先退出界面再安装。macOS 27 / Apple Silicon 实测；其他系统未实测。本地 ad-hoc 签名，未 Apple 公证，可能需要在系统隐私与安全性中允许打开。

## 行为及限制

- 每 5 秒扫描绑定的新模块（ME），自动保存，退出界面后后台仍运行。
- 自动发现 USB 插口，按固件及设备身份摘要核验，避免误读旧模块。
- 当前为用户这块 QDC507 模块的专用版本，不是任意模块即插即用版本；更换模块需要重新建立绑定。
- 短信位于 `~/DJISMS 短信/`：SQLite、可读收件箱及运行状态。
- 只读短信，不发短信、不拨号、不删除模块或 SIM 原件、不刷固件。
- 当前周期扫描只读 ME；SM 曾进行人工核对，但不属于此版本自动扫描范围。
- 部分旧迁移记录缺少正文，明确标记待核对；不宣称已恢复。长短信可能分片显示。
- 设备页面部分网络/SIM 容量数据暂不提供；不以短信接收状态代替网络连通证明。
- 通知由界面运行时提供；退出界面后仍保存，但不发桌面通知。
- 不使用 Google Drive、不联网上传，无遥测。软件手动升级。

## 源码构建

安装 Apple Command Line Tools 与 Python 后：

```
python3 build.py '/tmp/DJISMS.app'
```

构建使用系统 Swift、Clang、AppKit/IOKit；无第三方下载步骤。输出包含界面、只读协议桥接和后台接收组件。运行安装脚本注册服务。原版非商业许可证及第三方声明保留。本次发布替换旧版下载，旧提交仅保留在 Git 历史中。
