# DJISMS for macOS 1.3.2

Mac 本地短信接收工具，沿用经典界面。**这是绑定特定 QDC507 模块的研究版本，不是任意 DJI 模块通用安装包。** 不开发 iPhone 客户端；安卓版本独立维护。

## 下载与安装

1. 从 [v1.3.2 发布页](https://github.com/eric-zhou-xu/DJISMS/releases/tag/v1.3.2) 下载 DMG 和 SHA256SUMS.txt。终端运行 `shasum -a 256 下载文件路径`，与清单核对。
2. 要求 Apple Silicon；已验证环境为 macOS 27。其他系统及 Intel 未验证。需要 `/usr/local/bin/python3`，构建依赖 Apple Command Line Tools。
3. 退出 DJISMS 界面，打开 DMG，双击 **安装 DJISMS.command**。不要只拖动 App：接收服务也需要安装。
4. 安装目标为 `/Applications/DJISMS.app`。安装脚本会备份旧应用，并为当前用户注册登录启动及后台接收服务；不需要 sudo，不下载依赖，不删除历史短信。
5. 本包为 ad-hoc 签名，未 Apple 公证。若系统阻止打开，核对来源后使用系统“隐私与安全性”的允许打开入口；不要全局关闭 Gatekeeper。
6. 接入已绑定模块，打开应用查看接收状态。身份或固件不匹配会拒绝操作；朋友使用不同模块应先从源码研究绑定与兼容性，不能跳过校验硬套安装包。

## 日常使用与数据

- 自动接收：启动/连接时补查 ME（模块）和 SM（SIM），随后监听新短信通知；**不再每 5 秒查询短信**。界面/状态刷新不等于扫描模块。
- 手动补查：使用“立即补查”。通知端口不兼容、断线或后台异常时应查看状态，不能仅凭绿灯判断已收到短信。
- **保存并校验本地原始 PDU 后，逐条核对并删除模块/SIM 中对应原件。** 原件清理后，本机记录可能是唯一副本；不要未备份就清除应用数据。
- 删除本地短信：双击短信 → `•••` → “删除本机短信…”。确认后删除数据库和文本收件箱中的记录，保留去重摘要，避免同一原件再导入。此动作本身不向硬件发删除命令，不是物理安全擦除。
- 数据位置：`~/DJISMS 短信/`，包含 `短信.sqlite3`、`收件箱.txt`、`运行状态.json`。不要公开此目录或其截图。
- 退出界面后，当前用户后台仍接收保存；桌面通知依赖界面运行。需要 Mac 保持运行并连接模块。
- 无 Google Drive、无短信上传、无遥测；不发送短信、不拨号、不刷固件、不切换 USB 网络模式。软件手动更新。

## 已验证及限制

1.3.2 已在本机安装，关于页显示实际版本。单条真实短信删除、数据库及文本一致性、重启不再显示已验证；清空本地档案已核对数据库与文本为零。前序版本的真实短信接收、保存校验后逐条清理已验证。通知模式配置、监听和手动补查已验证，但 Mac 通知模式仍需更多新短信、休眠恢复及断线测试，不能宣称绝不漏收。

长短信可能按分段显示，旧迁移记录可能缺正文。部分网络/SIM 信息不提供；接收状态不证明网络可用。正常停止会尝试恢复 CNMI，意外拔出或强停无法保证恢复。与安卓不同，Mac 会在可靠保存后清理原件，安卓保留原件。

## 从源码构建

```sh
python3 build.py /tmp/DJISMS.app
```

输出路径必须不存在。使用系统 Swift、Clang、AppKit、IOKit，无构建时动态下载。将构建的 DJISMS.app、install.py 和“安装 DJISMS.command”放在同一目录安装。发布 DMG 中有安装说明，Release 同时提供源码 ZIP 和哈希清单。
