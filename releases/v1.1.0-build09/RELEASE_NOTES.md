# DJISMS 1.1.0 Build09 — 后续预发布版

此版本归档用户提供的最新 macOS 安装包，作为仓库现有 1.0.0 开发快照的后续版本。发布标签：`v1.1.0-build09`。

## 下载与兼容性

下载 Release 附件 `DJISMS-1.1.0-Build09.dmg`，拖动 DJISMS 到“应用程序”。支持 macOS 14 及以上，包含 Apple Silicon 和 Intel 架构。本次发布保留原始安装包，未修改二进制或虚增内部版本。

- 应用版本：1.1.0
- 内部 bundle 版本：1.5.9（保留原包值）
- 构建标识：20260925-startup-09
- 功能：只接收版，读取模块 ME 短信并保存在本机；不删除设备短信，不读取 SIM SM 存储。

## 已验证与限制

在接收安装包的 Apple Silicon Mac 上，磁盘映像校验通过，安装应用与映像内文件一致，应用及辅助程序的完整性签名校验通过。解除该应用的首次启动隔离后，主程序与核心服务已启动，本机档案初始化完成。实际硬件短信接收尚未验证。

本包只有临时本地签名，**没有 Developer ID 签名，也未经过 Apple 公证**。下载或隔空投送到另一台 Mac 后，系统仍可能阻止首次打开。本机解除隔离不是跨机器修复；本次发布不声称已解决所有机器的安装拦截。仅在确认来源可信时，通过 macOS“系统设置 → 隐私与安全性”允许打开。不要关闭全局 Gatekeeper 或 SIP。

## 源码对应关系

本机只有 Build09 安装包，没有对应的完整源码快照；仓库现有源码来自较早的开发快照。安装包内嵌的源码摘要记录在 manifest.json，但尚未验证其对应源码。因此，本 Release 的自动生成 Source code 压缩包 **不能当作 Build09 的已核实构建源码**。本发布提交只记录安装包、校验值和发布说明，不把旧源码改名冒充新版本。

后续正式版需补齐 Build09 源码快照、可复现构建证据、Developer ID 签名及 Apple 公证，并完成另一台 Mac 的安装及硬件测试。

## 档案迁移

应用升级会保留本机档案。跨机器迁移前正常退出旧电脑程序，再按应用内使用说明迁移 DJISMS 与 DJISMS-Startup 两个档案目录；也可以使用“恢复短信档案…”入口。安装包不含私人短信、账号凭证或个人档案。
